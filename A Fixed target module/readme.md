# Fixed-Target Network Simulation and Analysis

This folder contains the simulation and analysis code for the neuronal network model with a **fixed target module**.

In this condition, the first network module is designated as the target module and remains fixed throughout the simulation. External input is distributed between the target and non-target modules according to the input concentration parameter \(F\).

The folder provides a complete workflow from network construction and a single C++ simulation realization to Python-based analysis and visualization.

---

## Contents

The folder contains the following files:

### `simulation.cpp`

C++ source code implementing the neuronal network model and performing a single simulation realization.

The program:

* reads the network structure from an adjacency-list input file;
* reads the corresponding module-size information;
* initializes the neuronal and synaptic states;
* applies external input with module-dependent probabilities;
* keeps **module 1 as the target module** throughout the simulation;
* evolves the network dynamics in discrete time; and
* records network activity and synaptic/external activation statistics.

The code can be used with either the modular or non-modular network structure by selecting the corresponding input files.

### `analysis.ipynb`

Jupyter notebook for analyzing and visualizing the simulation output.

The notebook reads the output files generated by `simulation.cpp` and calculates network-level and module-level activity measures, spectral properties, target-module saliency, and network gain.

### Network input files

* `ModularAdjList.txt` — adjacency-list representation of the modular network.
* `NonModularAdjList.txt` — adjacency-list representation of the corresponding non-modular network.
* `BlockNodesNumberOfModularNetwork.txt` — number of nodes assigned to each module in the modular network.
* `BlockNodesNumberOfNonModularNetwork.txt` — corresponding module-size information for the non-modular network.

### Example simulation outputs

* `ActivityInTime.txt` — example output containing the activity of the eight network modules as a function of time.
* `NumberOfSynExtInTime.txt` — example output containing synaptic and external activation statistics for the target and non-target modules.

The example output files are included so that the analysis notebook can be tested without first running the C++ simulation.

---

## Model and Simulation

The network consists of \(N=2000\) neurons organized into eight modules. The first module is designated as the target module and remains fixed throughout a simulation.

The external activation probability is determined by the input concentration parameter \(F\). For a given value of \(F\), the target module receives enhanced external input, while the remaining input is distributed among the non-target modules.

The C++ program performs a **single realization** on the selected network topology. During the simulation, the network connectivity remains fixed while neuronal and synaptic states evolve according to the model equations.

The simulation records:

1. the activity of each network module over time;
2. the number of externally activated neurons in the target and non-target modules; and
3. the number of synaptically activated neurons in the target and non-target modules.

---

## Network Structures

The simulation can be performed using either a modular or a non-modular network.

### Modular network

Use:

```text
ModularAdjList.txt
BlockNodesNumberOfModularNetwork.txt
```

The adjacency-list file specifies the network connectivity, while the `BlockNodesNumber` file specifies the number of nodes assigned to each module.

### Non-modular network

Use:

```text
NonModularAdjList.txt
BlockNodesNumberOfNonModularNetwork.txt
```

The same simulation code can therefore be used to compare the dynamics obtained from modular and non-modular network structures.

## Running the Simulation

### 1. Select the Network Structure

In `simulation.cpp`, select the desired network input files.

For the modular network:

```text
ModularAdjList.txt
BlockNodesNumberOfModularNetwork.txt
```

For the non-modular network:

```text
NonModularAdjList.txt
BlockNodesNumberOfNonModularNetwork.txt
```

Make sure that the selected files are available in the working directory when the program is executed.

### 2. Set the Simulation Parameters

The main model and simulation parameters can be modified directly in `simulation.cpp`, including:

* network size;
* synaptic weights;
* synaptic lifetimes;
* simulation duration;
* input concentration \(F\); and
* external activation probability \(\eta\).

The parameters in the provided code correspond to the example simulation included in this folder.

### 3. Compile and Run

Using a C++ compiler such as `g++`:

```bash
g++ simulation.cpp -o simulation
```

Then run:

```bash
./simulation
```

The program generates the following output files:

```text
ActivityInTime.txt
NumberOfSynExtInTime.txt
```

These files contain the time-dependent quantities required by `analysis.ipynb`.

> **Note:** Running the simulation with the same output filenames will overwrite the existing example output files.

---

## Analyzing the Simulation Output

The notebook `analysis.ipynb` reads:

```text
ActivityInTime.txt
NumberOfSynExtInTime.txt
```

and performs the analysis of the simulated network dynamics.

The analysis includes:

* total network activity;
* activity of individual network modules;
* power spectrum of the network activity;
* visualization of the network adjacency structure;
* external activity in the target and non-target modules;
* synaptic activity in the target and non-target modules;
* target-module saliency;
* mean activity measures; and
* network gain.

The target module is **module 1** throughout the analysis.

To analyze a new simulation, replace the corresponding output files with the newly generated `ActivityInTime.txt` and `NumberOfSynExtInTime.txt` files and execute the notebook cells sequentially.

The example output files included in this folder allow the complete analysis pipeline to be tested without rerunning the simulation.

## Reproducibility

This folder is intended to provide a lightweight and self-contained reproducibility example rather than the complete ensemble of simulation data used to generate the manuscript results.

The supplied network input files define the connectivity used by the simulation, while the included output files represent example single-realization simulation results.

The same `simulation.cpp` code can be used with either the modular or non-modular network structure. The resulting output files can then be analyzed using the accompanying `analysis.ipynb` notebook.

The fixed-target condition is defined by keeping **module 1 as the target module throughout the simulation**, in contrast to the dynamic-target condition provided in the corresponding directory.
